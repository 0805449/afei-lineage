樓梯口天堂 B1.0 Alpha98.65 完整可玩媒體整合包

使用方式：
1. 請先把 ZIP 完整解壓縮到一般資料夾。
2. Windows 可雙擊「啟動遊戲.bat」，或直接雙擊 index.html。
3. assets/ 必須和 index.html 保持在同一層，請不要只單獨搬走 index.html。
